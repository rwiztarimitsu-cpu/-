# MF見積ツール（ブラウザ完結・2本）

工事見積の下請け見積を自社見積に変換し、マネーフォワード（MF）見積書の取込CSV（Shift-JIS・33列）を作る小さなWebツールです。
**HTML+CSS+JSのみ／ブラウザ内で完結／サーバー・DB・ログイン・AI API不使用**。データはどこにも送信されません。

| ファイル | 役割 | 入力 |
|---|---|---|
| `index.html` | **業者見積→自社見積コンバータ**：業者見積PDFを貼り付け→総額ランクを選ぶ→粗利を乗せた自社見積＋MF取込CSV | 総額ランク（1つ） |
| `mf_csv_maker.html` | **明細→MF取込CSVメーカー**：明細を入力→目標税込額に端数調整（不課税）を自動追加→MF取込CSV | 取引先・件名・目標税込・明細 |

GitHub Pages を有効にすれば `index.html` がそのまま公開URLで動きます。

## 使い方（index.html）
1. 業者見積の**PDFをドロップ／貼り付け（Ctrl+V・⌘V）／クリック選択**（複数可）。読み取った文字はテキスト欄に出るので手で修正できます。テキストの直接貼り付けも可。
2. **総額ランク**を選ぶ（低＝粗利率20%／中＝30%／高＝40%）。各ランクの税込総額が同時に表示されます。
3. 「MF取込CSVをダウンロード」→ `MF取込用_見積.csv`（Shift-JIS）

## 計算ルール
- 各行 売価 ＝ 原価 ÷ (1 − 粗利率) を百の位で切り上げ
- 税抜合計 → 消費税10%（四捨五入）→ 税込合計。粗利額・率を表示
- MF CSV：`csv_type=30301`／見積書行（取引先・件名・発行日=本日・敬称「御中」）＋品目行（数量1・式・税率10%）

## PDF読み取りの仕組み（pdf.js）
- 文字を座標付きで取得し、基準線±4pt以内を同一行にまとめる（表のセルずれ対策）
- 行間15pt以内で連なる行を同じセル塊とみなし、数値行が1つなら塊の先頭行（※注記除く）を品名に採用（品名＋説明複数行のセルに対応）
- 各行は「最初の数値の手前＝品名、最後の数値＝金額」。金額だけの行は直前の品名候補に紐付け（数値2個以上または単位付き・100円以上）
- 除外：小計/合計/消費税/税込/値引/端数調整/工事金額/◯%対象、「金」「円也」などのラベル、【…】の分類行、※注記
- 件名＝「工事名／件名／現場名」の行（TEL/FAX/〒以降は除去）

## 設定の変え方（`index.html` の `<script>` 先頭の定数）
| 定数 | 意味 |
|---|---|
| `RANKS` | ランク名と粗利率 |
| `ROUND_UNIT` | 丸め単位（既定100＝百の位切り上げ） |
| `TORI` | MF CSVの取引先名（**公開版はダミー。実運用では自社の取引先名に変更**） |
| `SAMPLE` | サンプルボタンの内容 |
| `SKIP_RE` / `KEN_RE` | 除外語・件名の検出語 |
| `TOL` / `GAP` | 同一行判定（pt）／セル塊判定（pt） |

## 制限
- **スキャン画像のPDF・写真は読めません**（文字層がないため。OCR未対応）
- 「品名」と「金額のみ（数量・単位なし）」が別行に分かれたPDFは誤認防止のため結合しません（テキスト欄で修正）
- pdf.js と encoding.js（Shift-JIS変換）を cdnjs から読み込むため、**オフラインでは動きません**。オフライン利用時はライブラリを同梱し `<script src>` をローカルパスに変更してください

## 依存（CDN・いずれもブラウザ内で動くJSライブラリ）
- pdf.js 3.11.174（PDF文字抽出）／ encoding-japanese 2.0.0（Shift-JIS変換）
